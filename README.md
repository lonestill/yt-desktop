# yt-desktop (YouTube Desktop)

Ультралегкий и быстрый нативный десктоп-клиент YouTube для macOS на Rust.

## Ключевые показатели

- **Размер бинарника:** `1.6 MB`
- **Потребление памяти (RSS):** `~90-110 MB` (против 800+ MB у Electron/FreeTube)
- **Зависимости:** `0` (использует системный WebKit с аппаратным ускорением Apple VideoToolbox)
- **Установка:** Собрал `.app` бандл, перетащил в `/Applications` — готово.

## Встроенные фичи

1. **Полный AdBlock:**
   - Вырезает все рекламные баннеры, спонсорские блоки, промо, мерч и плашки «Купи Premium».
   - **Авто-скип видеорекламы:** при обнаружении рекламного ролика видео мгновенно глушится, проматывается на скорости 16x и автоматически жмёт кнопку пропуска за доли секунды.
2. **Обход анти-адблока Google:**
   - Модальные окна «Блокировщики рекламы нарушают правила YouTube» автоматически удаляются из DOM вместе с оверлеями, а воспроизведение немедленно возобновляется.
3. **Авто-подтверждение «Продолжить просмотр?»:**
   - Фоновые клики по окну подтверждения при длительном прослушивании.
4. **Picture-in-Picture (PiP):**
   - Родная кнопка «Картинка в картинке» прямо в панели управления плеера.
   - Хоткей `Cmd + Shift + P`.
5. **Фоновое воспроизведение:**
   - Отключен фоновый троттлинг WebKit (`BackgroundThrottlingPolicy::Disabled`). Музыка и стримы не заикаются и не засыпают при сворачивании окна.
6. **Нативные хоткеи и жесты macOS:**
   - Свайпы двумя пальцами по трекпаду для навигации Вперед / Назад.
   - `Cmd + [`: Назад в истории.
   - `Cmd + ]`: Вперед в истории.
   - `Cmd + R`: Перезагрузить страницу.
   - Сохранение геометрии и позиции окна между перезапусками.
7. **Персистентность сессии:**
   - Сессия, Google-логин, история просмотров и настройки хранятся в `~/Library/Application Support/yt-desktop/web_profile`.

## Сборка

```bash
# Сборка готового YouTube.app
./build_app.sh

# Или запуск в режиме разработки
cargo run --release
```
