# yt-desktop (YouTube Desktop)

Ультралегкий и быстрый нативный десктоп-клиент YouTube для macOS на Rust с встроенным обходом блокировок ТСПУ (DPI).

## Ключевые показатели

- **Размер бинарника:** `2.2 MB`
- **Потребление памяти (RSS):** `~100 MB` (против 800+ MB у Electron / FreeTube)
- **Зависимости:** `0` (системный WebKit + Apple VideoToolbox + встроенный Tokio-прокси)
- **Установка:** Дважды кликнул по `.app` — работает из коробки.

## Встроенные фичи

1. **Встроенный обход DPI / ТСПУ (Zero-Config):**
   - Движок `desync` из `twitter-swarm` интегрирован прямо внутрь приложения.
   - При старте поднимает локальный HTTP CONNECT прокси на динамическом эфемерном порту `127.0.0.1:0`.
   - WKWebView нативно ходит через него через системный `Network.framework` (`mac-proxy`).
   - Парсит TLS ClientHello, находит границы SNI для `*.googlevideo.com`, `*.youtube.com`, `*.ytimg.com` и режет пакет на части (`TCP_NODELAY` + micro-delay 2ms).
   - Коробки ТСПУ не могут собрать SNI и пропускают видеопоток на полной скорости провайдера (1080p, 4K, 60fps) без VPN и рута.
2. **Полный AdBlock:**
   - Вырезает все рекламные баннеры, спонсорские блоки, мерч и плашки «Купи Premium».
   - **Авто-скип видеорекламы:** мгновенно глушит звук, разгоняет ролик на 16x и жмёт кнопку пропуска за 50 мс.
3. **Обход анти-адблока Google:**
   - Модальные окна «Блокировщики рекламы нарушают правила» сносятся из DOM на лету, плеер не встает на паузу.
4. **Picture-in-Picture (PiP):**
   - Кнопка в плеере + хоткей `Cmd + Shift + P`.
5. **Фоновое воспроизведение:**
   - Отключен троттлинг фоновых вкладок WebKit (`BackgroundThrottlingPolicy::Disabled`).
6. **Нативные хоткеи и жесты:**
   - Трекпад: свайпы двумя пальцами Вперед/Назад.
   - `Cmd + [`: Назад, `Cmd + ]`: Вперед, `Cmd + R`: Перезагрузка.
   - Запоминание геометрии окна.
7. **Персистентность:**
   - Все куки, история и логин хранятся в `~/Library/Application Support/yt-desktop/web_profile`.

## Сборка и запуск

```bash
# Сборка готового бандла:
./build_app.sh

# Запуск приложения:
open YouTube.app
```
